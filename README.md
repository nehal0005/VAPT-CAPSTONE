## 📖 About

This repository is a collection of machines I have solved, each written up as a professional security report. Every report explains **what was found, how it was exploited, how serious it is, and how to fix it**, in plain, easy-to-follow language.

---

## 📦 What's Inside

| Type | What you get |
|------|--------------|
| 🔓 **Penetration Testing Reports** | Full exploitation walkthroughs, from recon to access, with commands and screenshots |
| 🔍 **Vulnerability Assessment Reports** | Nessus scan results with findings grouped by severity |
| 📊 **CVSS Scoring** | A severity score and rating for every vulnerability |
| 💥 **Impact Summary** | What an attacker could do and why it matters to a business |
| 🛠️ **Remediation Steps** | Clear, practical fixes to close each issue |

---

## 🧾 What Every Report Contains

1. **Executive Summary**: a short overview for non-technical readers
2. **Scope & Methodology**: what was tested and how
3. **Findings**: each vulnerability with its description, affected service, and evidence
4. **CVSS Score & Severity**: Critical / High / Medium / Low
5. **Exploitation Steps**: the attack path, step by step *(pentest reports)*
6. **Impact Analysis**: the risk if the issue is left unfixed
7. **Remediation**: how to patch or harden the system
8. **Conclusion**: overall risk and recommendations

## 🚀 How to Use This Repo

1. Browse the folder for the report type you want.
2. Open a report and start with the **Executive Summary**.
3. Follow the exploitation steps to learn the technique.
4. Read the **Remediation** section to see how defenders fix the issue.
